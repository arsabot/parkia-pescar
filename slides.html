Estacionar Hoy es Perder Tiempo y Plata

Una experiencia frustrante para quien maneja y un negocio poco optimizado para quien tiene un estacionamiento.

🚗

Quien Maneja (Conductor)

  • ⏱️ 20 minutos perdidos: Dando vueltas a la manzana para encontrar un lugar libre.
  • ⛽ Gasto inútil de nafta: Combustible y batería quemados sin sentido, más estrés y demoras.
  • 🚫 Incertidumbre total: Llegás a la reunión o al médico y el estacionamiento está "Completo".
🏢

Quien Cobra (Dueño de Garaje)

  • 📉 Cocheras vacías: Hasta un 35% de plazas desocupadas en horarios valle sin nadie que las reserve.
  • 📝 Gestión prehistórica: Anotando patentes a mano en cuadernos, tickets de papel que se pierden.
  • 💸 Dinero que se escapa: No tienen forma de atraer a los miles de conductores que pasan cerca.

¿Cómo Funciona la App? (En 3 Pasos)

Tan intuitivo como pedir un auto con Uber o una habitación con Airbnb.

PASO 01

1. Buscás en el Mapa

Abrís la web desde el celular o computadora. Ves en el mapa los garajes cercanos, su tarifa por hora, fotos y comodidades (Techado, Seguridad, Carga Eléctrica).

📍 Con botón rápido "Cerca de mí"

2. Elegís tu Cochera

Seleccionás el horario en el que vas a estar y la plaza exacta que querés (ej: A-04 en Planta Baja). La app calcula el precio exacto al segundo.

Arquitectura del Proyecto

¿Cómo Está Estructurado PARKIA?

Una arquitectura desacoplada, clara y modular: Frontend web ligero + Backend REST API robusto.

🎨 PARKIA FRONT

Frontend Modular

Interfaz web sin dependencias pesadas, ultra rápida y adaptable a celulares y escritorios.

📁 Parkia Front/
├─ 📄 index.html (Home y Mapa)
├─ 📁 vistas/ (Buscador, Detalle, Reserva, Perfil)
└─ 📁 css/ (Diseño responsivo y estilos)
🗺️ Leaflet + OpenStreetMap: Mapas interactivos sin costo de API keys.
⚡ COMUNICACIÓN

API REST & JSON

Integración en tiempo real mediante peticiones asíncronas con autenticación JWT segura.

🔗 Endpoints Principales:
├─ /api/estacionamientos/ (Listado y filtros)
├─ /api/estacionamientos/{id}/ (Detalles)
├─ /api/auth/login/ & register/ (JWT)
└─ /api/auth/demo-login/ (Acceso demo rápido)
🔄 CORS & SimpleJWT: Conexión limpia y desacoplada entre front y back.
⚙️ BACKEND DJANGO

Lógica de Negocio y BD

Estructura por apps de Django para escalar funciones de manera modular y mantenible.

📁 backend/apps/
├─ 📁 users/ (Usuarios, Autos, Roles, Suscripciones)
├─ 📁 estacionamientos/ (Gestión y filtros)
├─ 📁 parking/ (Disponibilidad y reservas)
└─ 📁 config/ (Settings, URLs y Seguridad)
🛡️ Base de Datos Relacional: Control de plazas libres, reservas y usuarios.
